# Gateway API ingress

Use this file with the procedure in `../SKILL.md`.

Use Gateway API resources first. Use an Istio resource (`EnvoyFilter`, `DestinationRule`, `ServiceEntry`) only for what Gateway API cannot express.
Do not keep a classic Istio `Gateway`, a `VirtualService` or the `istio/gateway` chart.
Use the corvina-k8s ingress (`charts/corvina-app/templates/istio-http.yaml`) as the reference.

| Before | After |
|---|---|
| `istio/gateway` chart dependency, `istio-gateway` values | `Gateway` (class `istio`) generated by istiod; values `gateway.service`, `gateway.resources`, `gateway.autoscaling` |
| Istio `Gateway`, `VirtualService` | `Gateway`, `HTTPRoute` |
| `corsPolicy` with regular expressions | `CORS` filter of `HTTPRoute`: origins are `<scheme>://<host>[:<port>]`, the host may start with `*.` |
| `ServiceMonitor` of the gateway | `PodMonitor` on the label `gateway.networking.k8s.io/gateway-name` |
| pod label `istio: <name>` in NetworkPolicies | pod label `gateway.networking.k8s.io/gateway-name: <app>-gateway` |
| istiod 1.29, `PILOT_IGNORE_RESOURCES` | istiod 1.31.3 from `oci://ghcr.io/istio/release/charts`, no `PILOT_IGNORE_RESOURCES` |

Details that break silently:

- The `Gateway` must have the label `istio.io/rev` with the revision of the app istiod (the release name).
- Use one listener for each hostname (the host and `*.<host>`). Istiod uses the hostnames for SNI.
- In `certificateRefs`, do not write `group: core`. Omit `group`.
- Istiod generates the Deployment and the Service `<gateway>-istio`. Set their fields with the `parametersRef` ConfigMap (keys `service`, `deployment`, `horizontalPodAutoscaler`).
- Gateway API CRDs v1.6 or later must be in the cluster.
- On minikube, the CoreDNS rewrite for app hosts is in corvina-k8s (`charts/minikube-patch-corefile.sh`). It must point to `<app>-gateway-istio`. Tell the user if it does not.
- In `values.minikube.yaml`, `networkPolicy.corvinaIngress` must select the corvina-k8s http gateway pods (`gateway.networking.k8s.io/gateway-name: corvina-http-gateway`).
