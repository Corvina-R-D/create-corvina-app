# @corvina/nestjs-app-common-lib

Shared NestJS code of the Corvina apps generated by create-corvina-app: utils, decorators, pagination, error handling and the Corvina JWT auth.
Only generic code lives here: an app-specific variant stays in the app, as a subclass or a local file.

```sh
npm install @corvina/nestjs-app-common-lib
```

`@nestjs/common`, `@nestjs/core`, `@nestjs/swagger`, `rxjs`, `sequelize` and `sequelize-typescript` are peer dependencies:
the decorators inject by class (`Logger`, `Sequelize`), so the app and the library must share one copy.

## Setup

The app module provides what the library injects:

```ts
import { CACHE_SERVICE, INSTALLATION_SERVICE, Logger, provideCorvinaAuth } from '@corvina/nestjs-app-common-lib';

@Module({
  providers: [
    Logger, // Logger, MeasureTime, Retry, CacheMethod, guards
    { provide: CACHE_SERVICE, useClass: CacheService }, // CacheMethod, CorvinaJwtService
    { provide: INSTALLATION_SERVICE, useExisting: InstallationService }, // auth guards
    ...provideCorvinaAuth(), // 'ICorvinaJwtService'
  ],
})
export class AppModule {}
```

```ts
// main.ts
const app = await NestFactory.create(AppModule);
app.useGlobalFilters(new GlobalExceptionFilter());

// controllers
@UseInterceptors(LoggingInterceptor)
```

| Env variable | |
|---|---|
| `LOG_LEVEL` | pino level, default `info` |
| `LOG_TO_FILE` | path of a log file; stdout when unset |
| `INSTALLATION_HOSTS_WHITELIST` | required by the auth: comma separated url patterns of the allowed openid configurations, `*` for any |
| `MANIFEST_ID` | app id checked by `CorvinaCoreGuard` in the `app:` scope |

## Logging

| Export | Description |
|---|---|
| `Logger` | Injectable pino logger with `trace`, `debug`, `info`, `warn`, `error`, `fatal`. Pass an object (fields, or an `Error`) and/or a message: `logger.info({ id }, 'created')`. `err`/`error` fields are serialized with message and stack |
| `ILogger`, `LogParams` | interface of `Logger` and of its arguments |
| `getLoggerOptions()` | pino options of `Logger` (level from `LOG_LEVEL`, ISO timestamp, error serializers), for another pino instance |
| `loggerDestination` | pino destination of `Logger`: the `LOG_TO_FILE` file, or `undefined` (stdout) |
| `LoggingInterceptor` | logs `url`, `method`, `statusCode` and `executionTime` of every request |

## Decorators

Method decorators; they inject `Logger` (and `'ICacheService'` or `Sequelize`) in the class, which must be a Nest provider.

| Export | Description |
|---|---|
| `CacheMethod({ prefix?, ttl?, keyBuilder? })` | caches the result of an async method in the `'ICacheService'`. Key: `${prefix}${method}(${JSON args})` or `keyBuilder(args)`; `ttl` in seconds. Falsy results are not cached; a cache failure (e.g. redis down) logs a warning and calls the method |
| `SequelizeTransaction({ isolationLevel? })` | runs an async method in a transaction, passed as `{ transaction }` in its (single, object) argument; commits on success, rolls back on error. A `transaction` already in the argument is reused, so nested calls share it |
| `Retry({ nRetries, ms, applyRandomToMs?, handleError?, name? })` | retries an async method up to `nRetries` times, waiting `ms` between attempts, and returns its result |
| `continueWhenCouldNotSerializeAccessDueToConcurrentUpdate` | `handleError` for `Retry`: retries only the postgres serialization failures (`40001`) |
| `MeasureTime({ logArgs? })` | logs the execution time of a method (sync or async), with its arguments unless `logArgs: false` |

```ts
@SequelizeTransaction()
@Retry({ nRetries: 3, ms: 200, handleError: continueWhenCouldNotSerializeAccessDueToConcurrentUpdate })
async update({ id, transaction }: { id: string } & ITransactionOptions) { ... }

@CacheMethod({ prefix: 'device-', ttl: 60 })
async getDevice(id: string) { ... }
```

## Utils

| Export | Description |
|---|---|
| `ICacheService`, `CACHE_SERVICE` | cache the app provides under `'ICacheService'`: `get(key)`, `set(key, value, ttlSeconds?)`, `del(key)` |
| `retry(fn, options)` | function form of `Retry`: calls `fn` up to `nRetries` times; throws when all attempts fail. `handleError(nRetries, err)` returns `{ continue, avoidRethrow? }` to stop early, rethrowing or not |
| `queueHandler(queue, { numberOfParallelPromises? })` | runs (and empties) an array of async functions, at most `numberOfParallelPromises` (default 5) at a time |
| `matchUrl(url, rule)` | whether `url` matches a wildcard rule (`https://*.corvina.io/*`) |
| `removeDuplicates(array)` | the strings of `array` without duplicates |
| `chunk(array, size)` | `array` split into chunks of at most `size` items, the last one shorter (native replacement of lodash `chunk`); no chunks for a `size` lower than 1 |
| `deepMerge(target, ...sources)` | new object with the plain objects of `sources` deep merged into `target` (native replacement of lodash `merge`); `undefined` values are skipped, arrays and other values are replaced, not merged by index |
| `isValidSemver(version)`, `semverMajor(version)` | native replacements of `semver.valid` / `semver.major` (a leading `v` is accepted); `semverMajor` throws a `TypeError` for an invalid version |
| `addPeriod(date, period, ordinal?)` | `date` plus an ISO 8601 duration (`P1M`, `1Y`, …), `ordinal` times; month and year ends are clamped (Jan 31 + 1M = Feb 28/29) |
| `subPeriod(date, period)` | `date` minus an ISO 8601 duration, clamped like `addPeriod` |
| `calculatePercentage(endDate, period, now?)` | days left until `endDate` as a fraction of `period` (0.5 = half the period left), at most 1 |
| `toNumber(value, { default?, min?, max? })` | integer of a string or number; `default` when missing or not a number, then clamped to `min`/`max`. `0` is a value, not a missing one |
| `toBoolean(value)` | `true` for `true`, `'true'` and `'1'` (any case) |
| `toDate(value)` | `Date` of a string (a `Date` is returned as is) |
| `toArray(value)` | a string wrapped in an array (an array is returned as is), e.g. for repeated query params |
| `toLowerCase(value)`, `trim(value)` | string transforms, e.g. for `class-transformer` `@Transform` |

## Errors

| Export | Description |
|---|---|
| `CustomError<TContext>(code, message, context?)` | app error with a numeric code and an optional context |
| `GlobalExceptionFilter` | maps `CustomError` → 400 `{ errorCode, errorMessage, errorContext }`, `PayloadTooLargeException` → 413, NestJS `HttpException` → its status and body (404s logged as warnings), anything else → 500 (logged). Extend it, handle your errors and call `super.catch()` for the rest |

## Pagination

| Export | Description |
|---|---|
| `ParsePagePipe` | `page` of a query param or body: 0 when missing (or empty), otherwise a whole number ≥ 0; 400 for anything else (`abc`, `1.5`, `10abc`, `-1`) |
| `ParsePageSizePipe` | `pageSize` of a query param or body: 10 when missing (or empty), otherwise a whole number ≥ 1; 400 for anything else (`abc`, `1.5`, `10abc`, `0`) |
| `getOffsetAndLimit({ offset?, limit? })` | defaults `offset` 0 and `limit` 10; `CustomError` when `limit` is not in 1..1000 |
| `PaginatedDto<T>` | page response: `content`, `totalPages`, `totalElements`, `last`, `number`, `size` |
| `mapToPaginatedResponse({ rows, count, page, pageSize })` | `PaginatedDto` of a sequelize `findAndCountAll` page |
| `ApiPaginatedResponse(Model)` | swagger decorator of a `PaginatedDto` of `Model` (add `@ApiExtraModels(PaginatedDto, Model)`) |

```ts
@Get()
@ApiPaginatedResponse(DeviceDto)
async list(@Query('page', ParsePagePipe) page: number, @Query('pageSize', ParsePageSizePipe) pageSize: number) {
  const { rows, count } = await this.devices.findAndCountAll({ offset: page * pageSize, limit: pageSize });
  return mapToPaginatedResponse({ rows, count, page, pageSize });
}
```

## Auth

The token is validated against the realm of the installation: its signature (RS256) with the keys of the realm and its `iss`
with the `issuer` of the realm. The openid configuration and the keys are cached for a day (per realm); a JWKS
fetch is rate limited per realm, the openid configuration and JWKS requests time out after 5 seconds, and a cache failure falls back to the identity provider.
The `openIdConfigurationUrl` of a lifecycle event body (`POST /v1/<eventType>`) is used only when the installation does
not exist: for the `installed` event, and for an `uninstalled` event that has nothing to remove.

### Guards

| Export | Description |
|---|---|
| `CorvinaAuthGuard` | validates the bearer token (`Authorization: Bearer …`, any case) against the installation of the request: ids from `/v1/:instanceId/:organizationId/…`, or from the body of a lifecycle event. Sets `corvinaToken`, `instanceId`, `organizationId` in the request and in `response.locals`; 401 otherwise |
| `CorvinaInstallationRoleGuard` | after `CorvinaAuthGuard`: sets the `IServiceContext` and allows the users with the `realmValidationRole` of the installation |
| `CorvinaCoreGuard` | after `CorvinaAuthGuard`, on the lifecycle API: allows only core (`azp: core`) with the scopes `event:<eventType>` and `app:<MANIFEST_ID>@<orgResourceId>` |

```ts
@Controller('v1/:instanceId/:organizationId/devices')
@UseGuards(CorvinaAuthGuard, CorvinaInstallationRoleGuard)
export class DeviceController {
  @Get()
  list(@Context() context: IServiceContext, @CorvinaToken() token: ICorvinaToken) { ... }
}

@Controller('v1')
@UseGuards(CorvinaAuthGuard, CorvinaCoreGuard)
export class LifecycleController { ... }
```

Extension points are `protected` methods:

- `CorvinaAuthGuard`: `extractToken(request)`, `extractIds(request, context)`, `getLifecycleEvent(request)`, `getOpenIdConfigurationUrlOfNewInstallation(request)`, `onError(error, request)`
- `CorvinaInstallationRoleGuard`: `authorize(token, installation, context)`, which can also add fields to the context

```ts
@Injectable()
export class CorvinaAuthGuardFromHeaders extends CorvinaAuthGuard {
  protected extractIds(request: ICorvinaRequest) {
    return { instanceId: request.headers['x-instance-id'] as string, organizationId: request.headers['x-organization-id'] as string };
  }
}
```

### Service, decorators and helpers

| Export | Description |
|---|---|
| `provideCorvinaAuth()` | providers to spread in the app module: `CorvinaJwtService` as `'ICorvinaJwtService'`. Not a module, so the guards see the app's installation service |
| `CorvinaJwtService`, `ICorvinaJwtService`, `CORVINA_JWT_SERVICE` | `validateBearerToken({ token, instanceId, organizationId })` or `({ token, openIdConfigurationUrl })` → the decoded token; `getOpenIdConfiguration(url)` → the (cached) openid configuration of a realm, e.g. its `token_endpoint` |
| `IValidateBearerTokenInput` | input of `validateBearerToken` |
| `@CorvinaToken()` | parameter decorator: the `ICorvinaToken` set by `CorvinaAuthGuard` |
| `@Context()` | parameter decorator: the `IServiceContext` set by `CorvinaInstallationRoleGuard` |
| `extractBearerToken(header)` | token of an `Authorization` header (`Bearer` prefix case insensitive) |
| `getCorvinaUsername(token)` | `preferred_username` without the service account prefix |
| `ICorvinaInstallationService`, `INSTALLATION_SERVICE` | installation service the app provides under `'IInstallationService'`: `getInstallation({ instanceId, organizationId })` → installation or `null` |
| `ICorvinaInstallation` | installation fields the auth reads: `openIdConfigurationUrl`, `realmValidationRole?`, `orgResourceId?` |
| `InstallationNotFoundError` | thrown by the JWT service when the app is not installed (401 by default) |
| `CORVINA_EVENT_TYPE` | lifecycle events: `installed`, `uninstalled`, `renew` |
| `ICorvinaToken` | Keycloak access token claims |
| `IServiceContext<TInstallation>` | `{ installation, currentUser }` |
| `ICorvinaRequest`, `ICorvinaResponse`, `ICorvinaAuthResult` | what the guards read and set, without depending on express |
| `IOpenIDConfiguration` | openid configuration of a realm |

## Testing

`@corvina/nestjs-app-common-lib/testing`:

| Export | Description |
|---|---|
| `CorvinaJwtServiceMock` | `ICorvinaJwtService` that accepts any token (a fixed `ICorvinaToken` with the `realmValidationRole-testing` role) except `INVALID_TOKEN` |
| `INVALID_TOKEN` | the token the mock rejects |

```ts
{ provide: CORVINA_JWT_SERVICE, useClass: CorvinaJwtServiceMock }
```

The package is built with `strict` and ships its sources with source and declaration maps, so stack traces and go to definition point to the TypeScript code.

## Release

Publish a GitHub release with tag `nestjs-app-common-lib-vX.Y.Z` (`-beta.N` as a pre-release goes to the `beta` dist-tag):
`.github/workflows/publish-nestjs-app-common-lib.yaml` publishes it to npmjs.

```sh
npm ci && npm run lint && npm test && npm run build
```
