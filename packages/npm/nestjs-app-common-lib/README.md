# @corvina/nestjs-app-common-lib

Shared NestJS code of the Corvina apps generated by create-corvina-app: utils, decorators and the Corvina JWT auth.
Only generic code lives here: an app-specific variant stays in the app, as a subclass or a local file.

```sh
npm install @corvina/nestjs-app-common-lib
```

`@nestjs/common`, `@nestjs/core`, `@nestjs/swagger`, `rxjs`, `sequelize` and `sequelize-typescript` are peer dependencies:
the decorators inject by class (`Logger`, `Sequelize`), so the app and the library must share one copy.

## Utils

| Export | |
|---|---|
| `Logger`, `getLoggerOptions`, `loggerDestination` | pino logger (`LOG_LEVEL`, `LOG_TO_FILE`); the app provides `Logger` |
| `CacheMethod`, `ICacheService` | caches an async method in the `'ICacheService'` the app provides; ttl in seconds |
| `SequelizeTransaction` | runs an async method in a transaction, passed as `{ transaction }` in its argument |
| `Retry`, `retry`, `MeasureTime`, `queueHandler` | |
| `CustomError`, `GlobalExceptionFilter` | `CustomError` → 400, NestJS exceptions → their status, the rest → 500 |
| `LoggingInterceptor` | logs url, method, status code and execution time |
| `ParsePagePipe`, `ParsePageSizePipe`, `PaginatedDto`, `ApiPaginatedResponse`, `mapToPaginatedResponse`, `getOffsetAndLimit` | pagination |
| `addPeriod`, `subPeriod`, `calculatePercentage`, `toNumber`, `toBoolean`, `toDate`, `toArray`, `matchUrl`, `removeDuplicates` | |

## Auth

The module of the guarded controllers provides:

```ts
providers: [
  Logger,
  { provide: 'IInstallationService', useExisting: InstallationService }, // getInstallation({ instanceId, organizationId })
  { provide: 'ICacheService', useClass: CacheService },
  ...provideCorvinaAuth(), // 'ICorvinaJwtService'
],
```

`INSTALLATION_HOSTS_WHITELIST` (comma separated url patterns of the allowed openid configurations, `*` for any) is required.
`'ICorvinaJwtService'` also gives the (cached) openid configuration of a realm: `getOpenIdConfiguration(url)`.

| Guard | |
|---|---|
| `CorvinaAuthGuard` | validates the bearer token against the openid configuration of the installation; sets `corvinaToken`, `instanceId`, `organizationId` in the request and in `response.locals` |
| `CorvinaInstallationRoleGuard` | after `CorvinaAuthGuard`: sets the `IServiceContext` (`@Context()`) and allows the realm validation role of the installation |
| `CorvinaCoreGuard` | after `CorvinaAuthGuard`, on the lifecycle API: allows core with the event and app scopes of the request |

Extension points are `protected` methods:

```ts
@Injectable()
export class CorvinaAuthGuardFromHeaders extends CorvinaAuthGuard {
  protected extractIds(request: any) {
    return { instanceId: request.headers['x-instance-id'], organizationId: request.headers['x-organization-id'] };
  }
}
```

- `CorvinaAuthGuard`: `extractToken(request)`, `extractIds(request, context)`, `onError(error, request)`;
  the JWT service throws `InstallationNotFoundError` when the app is not installed (401 by default)
- `CorvinaInstallationRoleGuard`: `authorize(token, installation, context)`
- `GlobalExceptionFilter`: override `catch` and call `super.catch` for the errors the app does not handle

Tests: `@corvina/nestjs-app-common-lib/testing` exports `CorvinaJwtServiceMock` and `INVALID_TOKEN`.

## Release

Publish a GitHub release with tag `nestjs-app-common-lib-vX.Y.Z` (`-beta.N` as a pre-release goes to the `beta` dist-tag):
`.github/workflows/publish-nestjs-app-common-lib.yaml` publishes it to npmjs.

```sh
npm ci && npm run lint && npm test && npm run build
```
